## Vagrant

Vagrant is an open-source tool that automates the creation, configuration, and management of virtual machines through a single configuration file (the Vagrantfile). It works on top of third-party virtualization providers (such as VirtualBox, VMware, or QEMU) rather than performing virtualization itself. Its core purpose is to provide reproducible, portable development environments that can be version-controlled and shared, so that anyone can spin up an identical machine with a single command (vagrant up).
